עזי

הנהג, לא המפה

Claude Code הוא סוכן בינה מלאכותית של Anthropic שעובד ישירות על הקבצים שלכם. אתם מתארים בעברית רגילה את התוצאה שאתם רוצים, והוא פותח קבצים, עורך, בונה ומריץ פעולות עד שהיא מוכנה.

צ׳אט רגיל הוא מפה

מסביר איך מגיעים. את ההעתקה, ההדבקה והביצוע אתם עושים לבד.

Claude Code הוא נהג

לוקח אתכם לשם. אתם קובעים את היעד, והוא עוצר לשאול לפי הכללים שקבעתם.

בודקים לפני הגבול

  • מנוי Claude בתשלום. החשבון החינמי לא כולל את Claude Code. Pro עולה 20 דולר לחודש (17 בתשלום שנתי), Max מתחיל ב-100 ו-Ultra עולה 200. המחירון המלא נבדק ב-31.10.2026. ליתר ביטחון, בדקו שם לפני שאתם משלמים.
  • מחשב מתאים. Windows 10 גרסה 1809 ומעלה, macOS 13 ומעלה, או Ubuntu 20.04 / Debian 10 ומעלה. מעבד 64 ביט, 4GB זיכרון לפחות, וחיבור לאינטרנט.
  • לא צריך לדעת לתכנת. גם לא צריך Node.js או הרשאות מנהל. מדריך ישן שמתחיל ב-npm install? ההתקנה הרשמית כבר פשוטה ממנו.

עזי

פותחים אותו

לוחצים על Win + X ובוחרים Windows PowerShell או Terminal. אם בתחילת השורה כתוב PS C:\Users\you>, אתם במקום הנכון. אם אין PS, אתם ב-CMD, שמשתמש בפקודות אחרות.

לוחצים על Cmd + Space, מקלידים Terminal ולוחצים Enter. נפתח חלון עם סמן מהבהב, וזהו.

ברוב ההפצות לוחצים על Ctrl + Alt + T, או מחפשים Terminal בתפריט היישומים.

ארבעה חוקי תנועה

  • אין כאן עכבר. זזים עם החצים במקלדת, ושולחים עם Enter.
  • הדבקה: Ctrl + V או קליק ימני. Cmd + V. Ctrl + Shift + V.
  • בלם חירום: Esc עוצר את Claude באמצע פעולה.
  • יציאה: כותבים exit, או לוחצים Ctrl + D פעמיים בשורה ריקה.

ההתקנה

התחנה הזאת מציגה רק את מה שמתאים לבחירות שלכם בדרכון. התחרטתם? מחליפים כאן.

עזי

המסלול שלי

המחשב שלי

  1. מורידים ומתקינים נכנסים ל-claude.com/download, מורידים ומריצים את קובץ ההתקנה כמו כל תוכנה אחרת. ב-Linux מתקינים דרך apt לפי ההוראות הרשמיות. הגרסה עדיין בבטא, ל-Ubuntu ול-Debian.
  2. נכנסים לחשבון פותחים את Claude ומתחברים עם חשבון Anthropic שלכם.
  3. עוברים ללשונית Code היא בראש סרגל הצד. מופיעה בקשה לשדרוג? סימן שעדיין אין לכם מנוי בתשלום.
  4. בוחרים תיקייה מתחת לתיבת הכתיבה בוחרים את הסביבה המקומית (Local), לוחצים על בורר התיקיות ואז על Open folder…. התחילו בתיקיית תרגול ריקה.
זהו, אין עוד שלב. האפליקציה כבר כוללת את Claude Code, אז לא צריך Node.js ולא צריך את הטרמינל.
  1. Git for Windows (רשות, אבל מומלץ) מורידים מכאן ולוחצים Next בכל המסכים בלי לשנות דבר. לא צריך ללמוד Git. בלעדיו Claude Code פשוט ישתמש ב-PowerShell.
  2. פותחים טרמינל Win + X ואז Windows PowerShell או Terminal. לא צריך להריץ כמנהל, ולא לבחור באפשרות שכתוב בה x86. Cmd + Space, כותבים Terminal, ואז Enter. Ctrl + Alt + T, או מחפשים Terminal בתפריט.
  3. מדביקים את פקודת ההתקנה ולוחצים Enter 
    irm https://claude.ai/install.ps1 | iex
    curl -fsSL https://claude.ai/install.sh | bash
    זה מוריד ומריץ את המתקין הרשמי. בסוף תופיע ההודעה Claude Code successfully installed!
  4. פותחים חלון טרמינל חדש ובודקים חלון שהיה פתוח עדיין לא מכיר את הפקודה, אז חשוב לפתוח חדש. 
    claude --version
    מספר גרסה עם הכיתוב (Claude Code) אחריו אומר שהכול עבד. עדכונים ירדו מעכשיו לבד ברקע.
דרכים אחרות להתקין

מתוך CMD:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

WinGet (מתעדכן ידנית, עם winget upgrade Anthropic.ClaudeCode):

winget install Anthropic.ClaudeCode

Homebrew (מתעדכן ידנית, עם brew upgrade claude-code):

brew install --cask claude-code

יש גם התקנה דרך apt, dnf ו-apk, לפי ההוראות הרשמיות.

עובדים ב-VS Code? מחפשים Claude Code בחנות התוספים. התוסף מביא איתו עותק פרטי, ולכן הפקודה claude לא תעבוד בטרמינל עד שתתקינו גם בדרך הרגילה.

משהו השתבש? הדביקו את הודעת השגיאה במפענח השגיאות.

  1. נכנסים לכתובת claude.ai/code בדפדפן, או ללשונית Code באפליקציית Claude בטלפון.
  2. מחברים את GitHub ההדרכה במסך הראשון מחברת חשבון GitHub ומלווה אתכם במשימה ראשונה. אין לכם חשבון? פתיחה ב-github.com היא בחינם.
  3. בוחרים פרויקט ונותנים משימה המשימה רצה בענן וממשיכה גם כשסוגרים את המחשב.
מה לא עובד כאן: הסשן רץ בענן ולא רואה את הקבצים שעל המחשב שלכם. רוצים לעבוד על תיקייה מקומית? .

ספר הנהלים

Skill הוא נוהל שכותבים פעם אחת. כמו קלסר שמקבל עובד חדש ביום הראשון, רק שהעובד באמת קורא אותו.

עשיתם משהו טוב פעמיים? בפעם השלישית זה כבר צריך להיות Skill.

עזי

הדרך הקלה: פשוט מבקשים

סיימתם משימה ואתם מרוצים מהדרך? בקשו מ-Claude להפוך אותה לנוהל:

מה שעשינו עכשיו עבד מצוין. הפוך את זה ל-Skill אישי בשם meeting-summary, שאוכל להפעיל גם בפרויקטים אחרים. הצג לי את הקובץ לפני שאתה שומר אותו.

הדרך הידנית: 3 צעדים

  1. יוצרים תיקייה השם שלה יהפוך לפקודה, אז עדיף באנגלית. 
    mkdir "$env:USERPROFILE\.claude\skills\meeting-summary"
    mkdir -p ~/.claude/skills/meeting-summary
  2. שומרים בתוכה קובץ בשם SKILL.md התיאור למעלה עוזר ל-Claude להבין מתי הנוהל רלוונטי. 
    ---
description: מסכם פגישה למסמך פעולה. השתמש כשמבקשים לסכם פגישה, תמלול או שיחה.
---

1. קרא את התמלול או את ההערות.
2. כתוב בראש המסמך 3 משפטים: מה הוחלט.
3. צור טבלה: משימה, אחראי, תאריך יעד.
4. אם חסר אחראי או תאריך, כתוב "חסר". אל תנחש.
5. שמור כקובץ Word באותה תיקייה.
  3. מפעילים Claude יכול לזהות לבד שהנוהל מתאים, או שאתם מקלידים בשיחה חדשה: 
    /meeting-summary

סקילים של אחרים

דוגמה יפה מהקהילה הישראלית: editable-design של שירה רוט זליקוביץ. כל עיצוב שמבקשים מ-Claude מגיע גם עם עורך בדפדפן, ואפשר לשנות טקסט ולגרור דברים בלי לחזור לשיחה. למאגר גדול יותר, יש את הרשימה awesome-claude-code.

סקיל הוא קוד והוראות שרצים אצלכם. לפני שמתקינים משהו מהרשת, הדביקו את זה:
אל תתקין עדיין. קרא את כל הקבצים ב-[קישור], ואמור לי בעברית פשוטה: מה זה עושה, לאילו קבצים וחשבונות זה ניגש, האם זה שולח מידע החוצה, ומה מדאיג אותך. אחכה לתשובה ואחליט.

מתאם לחו״ל

MCP הוא מתאם חשמל: תקע אחד שמחבר את Claude לשירותים שאתם כבר משתמשים בהם, כמו Notion, Drive ואחרים.

מחברים רק מה שבאמת צריך. לכל חיבור יש מחיר של הרשאות וגם של מקום בשיחה.

עזי

מחברים שירות

בטרמינל, מחוץ ל-Claude. למשל, חיבור ל-Notion:

claude mcp add --transport http notion https://mcp.notion.com/mcp

אחר כך, בתוך Claude Code, מקלידים /mcp ומתחברים לחשבון. חיבורים נוספים שעברו בדיקה נמצאים בספרייה הרשמית.

מחפשים את השירות בספריית החיבורים של Anthropic, מחברים אותו לחשבון, ומאשרים את ההרשאות שהוא מבקש.

ומה זה Plugin?

חבילה שיכולה לכלול כמה דברים ביחד: סקילים, סוכנים, חיבורי MCP ועוד. מתקינים אותה בפקודה אחת, ו-/plugin פותח את התפריט.

אחרי שמחברים

מצא ב-Notion את כל המשימות שפתוחות אצלי השבוע, סדר אותן לפי דחיפות, וכתוב לי טיוטת תוכנית לשבוע. אל תשנה כלום ב-Notion.
שתי זהירויות. חיבור נותן ל-Claude גישה אמיתית לחשבון, אז התחילו בהרשאת קריאה בלבד אם יש אפשרות כזאת. ותוכן שמגיע מבחוץ, כמו מייל או דף אינטרנט, יכול להכיל הוראות שמישהו הטמין שם, אז עדיף לא לאשר פעולות רגישות על עיוור.

שלוש משימות אמיתיות

מכאן לומדים רק מעבודה. בחרו משימה אחת, העתיקו את הבקשה, ואז המשיכו בשיחה עד שאתם מרוצים.

התוצאה הראשונה היא טיוטה. הקסם קורה בבקשה השנייה והשלישית.

עזי

עמוד אישי באינטרנט

בנה לי דף אינטרנט אישי אחד בעברית, מימין לשמאל. אני [שם], ואני עוסק/ת ב[תחום]. שאל אותי קודם 3 שאלות על הקהל ועל הסגנון. הדף צריך להיראות טוב גם בטלפון, ובסוף תסביר לי איך לפתוח אותו.

בודקים: פותחים את הקובץ בדפדפן, מצמצמים את החלון לרוחב של טלפון, ומבקשים לשנות דבר אחד.

סדר בהוצאות

בתיקייה הזאת יש קבלות וחשבוניות. אל תשנה ואל תמחק את המקור. קרא אותן, בנה קובץ Excel חדש לפי תאריך, ספק, סכום וקטגוריה, והוסף גיליון סיכום לפי חודש. סמן כל קבלה שלא הצלחת לקרוא בוודאות.

בודקים: משווים שלוש שורות מול הקבלה עצמה. עובדים על עותק של הקבצים, לא על המקור.

כלי קטן משלכם

בנה לי אפליקציית משימות בקובץ HTML אחד, בעברית: הוספה, סימון ״בוצע״, מחיקה, וסינון לפי ״להיום״. המשימות יישמרו גם אחרי שסוגרים את הדפדפן. בלי שרת ובלי התקנות.

בודקים: מוסיפים משימה, סוגרים את הדפדפן, פותחים שוב, ורואים שהיא עדיין שם.

דלפק העזרה

נתקעתם? כאן מפענחים הודעות שגיאה, מוצאים פקודות, ומתרגמים מילים מוזרות לעברית.

מפענח השגיאות

    לא מצאתי התאמה. בקשו מ-Claude באפליקציה או בצ׳אט להסביר את השגיאה, או בדקו בעמוד התקלות הרשמי.

    שאלות נפוצות

    אפשר לעבוד איתו בעברית?

    כן. כותבים בעברית רגילה והוא מבין ועונה. ההערה היחידה היא שבחלק מהטרמינלים התצוגה של עברית הפוכה או מבולגנת, ואז האפליקציה נוחה יותר.

    הוא יכול להרוס לי משהו?

    הוא עובד באמת על קבצים, אז טעות היא אפשרית. לכן מתחילים בתיקיית תרגול, עובדים על עותקים, משתמשים ב-Plan לדברים גדולים, ועוצרים עם Esc כשמשהו נראה לא נכון.

    כמה זה עולה בפועל?

    השימוש נכלל במנוי, עם מגבלות לכל 5 שעות ולכל שבוע. משימות גדולות מגיעות למגבלה מהר יותר, ואז ממתינים או משדרגים. /usage מראה איפה אתם עומדים. לפרטים: עלויות, בתיעוד הרשמי.

    מה קורה עם הקבצים שלי מבחינת פרטיות?

    מה ש-Claude קורא נשלח לשרתים של Anthropic לצורך עיבוד. אל תפתחו אותו בתיקייה עם סיסמאות או מידע רגיש שאסור שיצא מהארגון, ובחשבון של עבודה בדקו קודם מה הנוהל. מדיניות השימוש בנתונים.

    איך מעדכנים?

    התקנה רגילה בטרמינל מתעדכנת לבד ברקע. מי שהתקין דרך Homebrew או WinGet מעדכן ידנית.

    איך מסירים אותו?

    יש הוראות לכל מערכת הפעלה בעמוד ההתקנה הרשמי.
